# Tools and Spares

Last updated: 2026-09-04

## Tools

- 必要な工具自体は一通り揃っている
- 課題は工具の内容ではなく、KOVE 450 Rallyのどこへ、どのように艤装するか
- 車体への搭載方法は「うなぎさん」に相談する

搭載時は以下を重視する。

- 重量位置
- 振動対策
- 防水
- 脱落防止
- 転倒時の損傷防止
- 取り出しやすさ

## Spares status

| Item | Status | Notes |
|---|---|---|
| 予備ミラー | 購入済み | 現車は可倒式ミラー装着済み |
| 予備レバー | 要購入 | TBIまでに準備 |
| 予備ペダル | 要購入 | TBIまでに準備 |
| 予備ブレーキパッド | 要購入 | TBIまでに準備 |
| 前後予備ホイール | 購入予定 | TBIまでに石原商店で購入 |
| ムース | 所有済み | モンゴルで使用した物を再利用予定。状態確認後に使用判断 |
