# TBI2027

SSER TBI 2027への参戦準備および記録を管理するプロジェクト。

## Purpose

TBI 2027を、Rally Mongolia 2028への二輪参戦に向けた実戦テストとして位置づける。

主な目的:

1. 装備品・艤装品の確認
2. 本人の体力と技術の確認

TBI 2027の競技成績だけを目的とはせず、Rally Mongolia 2028へ向けて車両・装備・身体・技術上の課題を抽出する。

## Load policy

身体に装着する必要のない物は、可能な限り車体へ積載する。

ただし、車両運動性能を過度に悪化させないことを前提とする。

リア上部は乗降時に足が引っかからないよう、原則として大きな荷物を積載しない。
リアへ積載する場合は左右サイドを優先する。
