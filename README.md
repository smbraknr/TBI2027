## Purpose

TBI 2027を、Rally Mongolia 2028への二輪参戦に向けた実戦テストとして位置づける。

主な目的:

1. 装備品・艤装品の確認
2. 本人の体力と技術の確認

TBI 2027の競技成績だけを目的とはせず、Rally Mongolia 2028へ向けて車両・装備・身体・技術上の課題を抽出する。

## Load policy

ライダーが背負う重量を減らすため、身体に装着する必要のない物は可能な限り車体へ艤装する。

TBI 2027のレギュレーションで携行が求められる品目は、公開後に正式確認したうえで車載配置を決める。
地図、非常食、エマージェンシーシート等を車載候補とする。

水はキャメルバックで背負う。

車載時は、車両運動性能、重量位置、防水、振動、脱落防止、転倒時の損傷、取り出しやすさを考慮する。
